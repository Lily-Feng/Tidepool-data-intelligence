TideTrack Studio

A privacy-first personal analytics toolkit for Tidepool data, built around private raw storage, governed lakehouse tables, and synthetic public examples.

What it does

  • Preserves authorized Tidepool data in private Amazon S3 storage
  • Transforms it in governed Databricks and Unity Catalog tables
  • Visualizes approved Gold metrics in a read-only Databricks App
  • Publishes docs on GitHub Pages

Get started

Open README.md, then follow the implementation specifications in docs/v1/.

Security first

Keep credentials and real health data out of GitHub and free/public analytics environments. Public examples use synthetic data only.
